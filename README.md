## Quizz application

This project is a reworked version of a quiz web app, redesigned as **Quizz application** for internship use. It is a responsive browser-based challenge built using **HTML, CSS, and JavaScript** with a cleaner modern theme and updated question bank.

The app presents randomized multiple-choice rounds, gives a **15-second timer** for each round, tracks score, and shows a final performance rank after completion. It also includes answer highlighting, smooth transitions, and a confetti celebration.

## Features

- Rebranded UI with a fresh layout and color system
- Randomized question and option order
- 15-second countdown for each round
- Correct/wrong answer highlighting
- Final score with rank-based feedback
- Restart challenge functionality
- Confetti animation on completion

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Purpose

The purpose of this version is to demonstrate front-end fundamentals with a distinct implementation style suitable for internship submission. It covers DOM manipulation, timer handling, state control, dynamic rendering, and responsive design.
